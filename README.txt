【東庄内小学校 ARスタンプラリー 説明書】

■ 今回の企画
 iPadのカメラで、9か所の「マーカー(目印の絵)」を読みとって遊ぶスタンプラリーです。
 ミニゲームとクイズで、地元の特産品などを学びます。

■ 公開しているページ(ここを開くと遊べます)
 https://ivy-icc.github.io/shonai-ar-stamp-rally/
 ・カメラを使うので、「https」で始まるURLが必要です(上のURLはOKです)。
 ・最初に、このURLのQRコードを1回読むだけです。あとは、マーカーにiPadをかざすと問題が始まります。

■ フォルダの中身
 index.html / style.css / app.js / games.js / data.js / story.js … アプリ本体
   (story.js は、オープニングとエンディングの場面の流れです)
 img/ … キャラクターの絵
 ar/ … all.mind(マーカーを読みとるためのデータ)
 markers/ … 印刷用のマーカー(spot1〜9のPNG画像と、A4印刷用のPDF)
 ※ 中のファイルは、名前を変えたり、動かしたりしないでください。動かなくなります。

■ マーカーの番号
 1番 梨 / 2番 千両なす / 3番 いちご / 4番 トマト / 5番 ほうれんそう
 6番 ゆず / 7番 ブルーベリー / 8番 由布岳 / 9番 ミツマタ

■ 当日の使い方
 1. iPadのSafariで、上のURLを開く(またはQRコードを読む)
 2. カメラの許可を聞かれたら「許可」を押す
 3. iPadを横向きにして、マーカーにむける
 4. マーカーにむけたまま、5秒くらい、じっと待つ(読みとれたら、ゲームが始まります)
 5. ゲームとクイズをクリアするとスタンプがもらえます。9つそろうと、最後のゲームです。

■ iPadの取り扱い方(とても大事です)

【始める前の準備】
 ・iPadは、充電を十分にしておく(残りが少ないと、動きが重くなることがあります)
 ・画面の明るさを、できるだけ明るくしておく
 ・カメラのレンズ(iPadの背中側)を、やわらかい布でふいておく。指紋や汚れがあると、読みとりにくくなります
 ・Wi-Fiにつながる場所で、先にページを1回開いておく(通信費をおさえるためです。くわしくは「通信について」を見る)
 ・ほかのアプリは、閉じておく(動きが軽くなります)
 ・Safariは、「プライベートブラウズ」にしない(スタンプの記録が残らなくなります)
 ・iPadは、横向きにする。向きが変わってしまうときは、画面の向きのロックを使う

【マーカーの読みとり方】
 ・★カメラは、マーカーに向けたまま、じっと待つ
   読みとりには、数秒かかります。5秒くらいは、動かさずに待ってください。
   すぐに読みとれないのは、故障ではありません。
 ・マーカーが、画面の中に大きく、全体が入るようにする(目安: 画面の半分以上)
 ・マーカーの正面から向ける。斜めすぎると、読みとりにくくなります
 ・iPadを、両手でしっかり持つ。手がふるえると、読みとれません
 ・読みとれたら、そこでiPadを大きく動かさない
 ・ほかのマーカーが、画面のはしに入らないようにする。まちがって読むことがあります
 ・読みとれないときは、いったんカメラをマーカーから外して、もう一度向けると、読めることがあります

【明るさ】
 ・★暗い場所では、読みとれません。明るい場所で使ってください
 ・マーカーの上に、iPadや自分のかげがかからないようにする
 ・窓ぎわで、強い光が後ろから入る場所(逆光)は、避ける
 ・直射日光が、マーカーに強く当たる場所も、避ける(白くとんで、読めなくなります)

【子どもに伝えること】
 ・「マーカーを、画面の中に大きく入れて、5秒くらい、じっと待ってね」
 ・「暗いところ、ぴかっと光るところは、読めないよ」
 ・「iPadは、落とさないように、両手で持ってね」

■ マーカーを印刷するとき
 ・★古いマーカーは使えません。markers/ の中の、新しいマーカーを印刷してください。
 ・★つやのある紙(光沢紙、写真用紙)や、つやのあるラミネートは、不向きです。
   光が反射して、マーカーの絵が見えなくなり、読みとれなくなります。
 ・印刷は「マット紙(つや消し)」にしてください。ラミネートをするなら、つや消しのものを使う
 ・マーカーは、平らに貼る。折れたり、丸まったり、しわがあると読みとれません
 ・汚れたり、色があせたりしたら、新しく印刷し直す
 ・サイズは、A4のまま使う。小さくすると、読みとりにくくなります
 ・貼る高さは、子どもが、まっすぐ向けやすい高さにする
 ・マーカーの絵を変えたときは、all.mind を作りなおす必要があります。自分で変えずに、制作者に相談してください。

■ 通信(データ通信量・通信費)について

【どのくらい通信するか】
 ・ページを最初に開くとき、データを読みこみます。マーカーのデータ(all.mind)だけで、約8.4MBあります。
   そのほかの部品や画像もあわせると、1台につき、最初の1回で、10MB以上は使うと考えてください。
 ・カメラの映像は、インターネットには送りません。iPadの中だけで処理するので、遊んでいる間の通信は、ほとんどありません。
 ・スタンプの記録も、iPadの中に保存するだけで、通信しません。

【通信費がかかる場合】
 ・Wi-Fiにつながっていない状態で、モバイル通信(SIM)を使うと、通信費がかかります。
   1台10MBでも、台数が多いと、合計は大きくなります(例: 30台 × 10MB = 約300MB)。
 ・スマホの「テザリング(スマホをWi-Fiの代わりにする機能)」を使うと、そのスマホの通信量を使います。
   契約の通信量が、なくなったり、速度が遅くなったりするので、注意してください。

【おすすめのやり方】
 1. 会場にWi-Fiがあるか、事前に確認する
 2. ある場合: iPadを、そのWi-Fiにつないで、ページを1回開いておく
 3. ない場合: 前日までに、学校などのWi-Fiで、全部のiPadで、ページを1回開いておく
    (一度読みこんだデータは、iPadが覚えているので、当日の通信が少なくなります)
 4. 念のため、当日も、会場にWi-Fiがあると安心です

【注意】
 ・iPadが覚えているデータは、消えることがあります(Safariの履歴を消す、容量が足りなくなる、など)。
   「前日に開いたから、当日は絶対に通信しない」とは言いきれません。
 ・インターネットにつながらないと、最初のページが開けません。

■ スタンプの記録を全部消す(スタッフ用)
 URLのうしろに ?reset を付けて開くと、そのiPadの記録が消えます。
 例) https://ivy-icc.github.io/shonai-ar-stamp-rally/?reset
 ・リセット用のQRコードを作ってあります。スタッフだけが使い、参加者には渡さないでください。
 ・記録は、iPadの中(Safariの記憶)に残ります。1人1台で使う前提です。
 ・Safariの「プライベートブラウズ」で開くと、記録が残りません。ふつうのタブで開いてください。
 ・Safariの履歴やWebサイトデータを消すと、スタンプも消えます。

■ カメラなしで動きを確認する(確認用)
 URLのうしろに ?debug を付けると、マーカーがなくても、画面のボタンで各ゲームを試せます。
 例) https://ivy-icc.github.io/shonai-ar-stamp-rally/?debug
 ・?debug&skip … オープニングと「あそびかた」を飛ばす
 ・?debug&skip&spot=3 … 3番のゲームだけを開く(1〜9)
 ・?debug&skip&end … エンディングだけを見る

■ うまくいかないとき
 ・画面がまっくら → カメラの許可が「許可」になっているか確認する(設定 → Safari → カメラ)
 ・読みとらない → 明るさ・距離・かげ・紙のつやを、順番に確認する
 ・ゲームの途中で止まった → Safariを閉じて、もう一度URLを開く(スタンプの記録は残ります)
 ・何をしてもだめなとき → ほかのiPadで試す

■ 確認ずみのこと・情報のもと
 ・iPadの実機で、カメラ、マーカーの読みとり、ひっくり返す迷路の動きを確認ずみ
