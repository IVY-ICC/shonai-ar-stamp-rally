【東庄内小学校 ARスタンプラリー(リニューアル版)】

■ 中身
 index.html / style.css / app.js / games.js / data.js / story.js … アプリ本体
   (story.js は、オープニングとエンディングの場面進行です)
 img/ … キャラクターの絵(SVG)
 ar/  … all.mind(マーカーの読みとりデータ)
 markers/ … 印刷用マーカー

■ マーカーと all.mind
 ar/all.mind … 9枚のマーカーをまとめた読みとりデータ(作成ずみ。順番は下のとおり)
 markers/ … 印刷用のマーカー画像(spot1〜9のPNG)と、A4印刷用PDF
      1番 梨 / 2番 千両なす / 3番 いちご / 4番 トマト / 5番 ほうれんそう
      6番 ゆず / 7番 ブルーベリー / 8番 由布岳 / 9番 ミツマタ
 ※マーカーの絵をかえたときは、all.mind を作りなおす必要があります
   (https://hiukim.github.io/mind-ar-js-doc/tools/compile に、上の順番で画像を入れる)。
 ※印刷は、マット紙(つや消し)がおすすめです。つやのある紙は、光が反射して読みとりにくくなります。

■ 公開のしかた(GitHub Pages)
 このフォルダーの中身を、そのままリポジトリに入れて、Pagesで公開する。
 カメラを使うので、https のURLが必要です。最初にそのURLのQRコードを1回読むだけで、
 あとはマーカーにiPadをかざすだけで、問題が始まります。

■ マーカーなしで動作を確認する
 URLのうしろに ?debug を付ける  例)…/index.html?debug
 画面に1〜9と「さいご」のボタンが出て、マーカーなしで各ゲームを試せます。
 ?debug&skip で、オープニングとあそびかたを飛ばせます。
 ?debug&skip&end で、エンディングだけを見られます(「エンディング」ボタンでも見られます)。
 さいごのなぞをクリアすると、エンディングが流れます。スタンプ帳からも、あとで見られます。

■ スタンプの保存
 iPadの中(localStorage)に保存します。1人1台の前提です。
 全部消す(スタッフ用):URLのうしろに ?reset を付けて開く  例)…/index.html?reset
   そのiPadのスタンプの記録が、すぐに消えます。リセット用のQRコードを作っておくと便利です(参加者には渡さない)。

■ 問題文を直す
 data.js の中の文章を直すだけで変わります。漢字は4年生までに習うものと地名だけにしてあります。

■ 確認が必要なこと
 ・ミツマタの群生地(庄内町大津留)は、YUFUINFOのページで確認済み
 ・由布岳の高さ(1583m・1580m)は前のコードの数字のまま
 ・iPadの実機で、カメラ、マーカーの読み取り、ひっくり返す迷路の動きを確認してください
