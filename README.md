小学校5・6年生が、学校のiPad(横向き)で遊ぶ、WebAR(カメラで読みとる)のスタンプラリーです。
庄内町・由布市の特産品(梨・千両なす・いちご・トマト・ほうれんそう・ゆず・ブルーベリー・由布岳・ミツマタ)を、
9つのマーカーを読みとりながら、ミニゲームとクイズで学びます。

## 遊び方の流れ
1. オープニング(かぐらちゃんが、庄内神楽祭りの前に町を案内)
2. 9か所のマーカーにiPadをむける → ミニゲーム → クイズ → スタンプ
3. 9つそろうと、神楽のぶたいのじゅんび(最後のゲーム)
4. エンディング

## 確認のしかた(カメラなし)
`index.html?debug` で開くと、マーカーなしで各ゲームを試せます。
- `?debug&skip` … オープニングとあそびかたを飛ばす
- `?debug&skip&end` … エンディングだけを見る
- `?debug&skip&spot=1`〜`9` … そのスポットのゲームだけを開く

## 使っている技術
HTML / CSS / JavaScript(ビルドなし)、A-Frame、MindAR(画像認識)、GitHub Pages。
スタンプは端末の中(localStorage)にだけ保存します。個人情報は集めません。
