## これは何?
小学校5・6年生が、学校のiPad(横向き)で遊ぶ、スタンプラリーです。
iPadのカメラで、9か所に貼った「目印(マーカー)」を読みとると、ミニゲームとクイズが始まります。
由布市庄内町の特産品(梨・千両なす・いちご・トマト・ほうれんそう・ゆず・ブルーベリー・由布岳・ミツマタ)を、遊びながら学べます。
アプリのインストールは不要です。ブラウザ(Safari)で開くだけで動きます。

## 公開ページ
https://ivy-icc.github.io/shonai-ar-stamp-rally/

## 遊び方の流れ
1. オープニング(かぐらちゃんが、庄内神楽祭りの前に町を案内)
2. 9か所のマーカーにiPadをむける → ミニゲーム → クイズ → スタンプ
3. 9つそろうと、神楽のぶたいのじゅんび(最後のゲーム)
4. エンディング

## カメラなしで試すには(確認用)
ページのURLのうしろに、次の文字を付けて開きます。マーカーがなくても、各ゲームを試せます。

| 付ける文字 | できること |
|---|---|
| `?debug` | 画面に1〜9と「さいご」のボタンが出て、好きなゲームを選べる |
| `?debug&skip` | オープニングと「あそびかた」を飛ばす |
| `?debug&skip&spot=1` 〜 `spot=9` | そのスポットのゲームだけを開く |
| `?debug&skip&end` | エンディングだけを見る |

例: https://ivy-icc.github.io/shonai-ar-stamp-rally/?debug&skip&spot=6 (ゆずのゲーム)

## 使っている技術
HTML / CSS / JavaScript(特別な作成ソフトは使っていません)、A-Frame と MindAR(カメラで絵を見つける部品)、GitHub Pages(ページの公開)。
スタンプの記録は、そのiPadの中にだけ保存します。個人情報は集めません。
